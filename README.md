# Байес

Это экспертная система на основе Байесовского вывода, написаная на Python 3.14. Программа считывает файлы формата .mkb и предоставляет интерфейс для проведения консультаций в области, определенной файлом.

## Запуск программы

### Способ 1: Готовый Exe

Программа доступна для скачивания в виде готового приложения, собраного под ОС Windows.
1. Скачать ExpertSystem.exe из Releases.
2. Запустить файл.
3. Через меню «Файл» открыть базу знаний .mkb.

### Способ 2: Самостаятельная сборка

Также есть возможность собрать и запустить программу самостоятельно, если готовое приложение не работает или установлена отличная от Windows система.
1. Если не установлен Python, нужно установить. Подходящая версия - 3.10 или новее
2. Клонировать репозиторий на устройство
3. Создать виртуальное окружение
4. Запустить программу
